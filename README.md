# GBSBBHARAT Coin (GBSBFY)

Official project information page for the proposed GBSBBHARAT Coin.

## Proposed token parameters
- **Name:** GBSBBHARAT Coin
- **Symbol:** GBSBFY
- **Initial supply:** 100,000,000 tokens (10 crore)
- **Decimals:** 18 (proposed)
- **Intended network:** Polygon
- **Token standard:** ERC-20

See [TOKENOMICS.md](./TOKENOMICS.md) for the proposed supply policy and deployment safeguards.

## Current status
The project information website is published on GitHub Pages. This does **not** mean the token has been deployed.

A Solidity contract source file and a live, verified blockchain contract address have not yet been confirmed in this repository. Do not treat GBSBFY as an issued token until the source code is added, reviewed, tested, and deployed, and the resulting address is verified on a blockchain explorer.

## Planned capabilities
Minting (if approved), burning, transfers, and owner permissions are proposed features, not verified live capabilities. Future minting can dilute existing holders, so permissions and supply controls must be reviewed before deployment.

## Before any mainnet deployment
1. Add and review the actual Solidity source.
2. Compile and run tests, including access-control and supply tests.
3. Test on a Polygon test network.
4. Obtain an independent security review.
5. Review applicable legal, tax, and consumer-protection requirements.
6. Deploy only after the owner reviews and explicitly approves the final contract and transaction.
7. Publish the verified contract address and explorer link here and on the website.

This repository does not promise token value, returns, liquidity, or exchange listing.
